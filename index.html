Features

主要功能

所有功能开箱即用，可自由组合与配置。

01

网页翻译

支持整页翻译、双语对照和仅译文模式，可自动或手动控制范围，支持 30+ 种语言互译。

02

划词与选中翻译

选中网页文字即可快速翻译、朗读和复制，让阅读外文内容更轻松。

03

输入框翻译

在聊天、评论、搜索或写作时快速翻译输入内容。

04

视频字幕翻译

支持 YouTube 等平台字幕翻译、双语字幕显示和字幕样式自定义。

05

多服务商翻译对比

可同时使用多个 AI 翻译服务对比结果，支持自定义 API 服务、模型和参数。

06

语音朗读

支持朗读原文或翻译结果，可调整朗读语言和语速。

07

术语表

可添加常用词汇和固定翻译，让翻译结果更符合你的表达习惯。

08

快捷键与悬浮球

支持自定义快捷键和悬浮按钮，随时快速开启或关闭翻译功能。

09

多语言界面

支持多种界面显示语言，方便不同地区的用户使用。

10

浅色与深色主题

可根据个人喜好或系统设置自动切换界面外观。

Getting Started

快速开始

  1. 安装扩展
    从 Chrome 应用商店安装鸿鹄 LinguaFlow。
  2. 打开设置
    点击浏览器工具栏中的扩展图标，打开悬浮窗或设置页面。
  3. 配置翻译服务
    在「提供商配置」中选择或添加你使用的 AI 翻译服务，必要时填写自己的 API Key。
  4. 开始使用
    打开任意网页开始翻译，或选中文字、输入框内容快速翻译。

FAQ

常见问题

鸿鹄 LinguaFlow 收费吗？
完全不收费。所有核心翻译与学习功能都免费开放，没有付费解锁，也没有使用次数、时间或功能限制。
需要注册或登录吗？
不需要。本扩展无需账号即可使用，也没有登录、托管 AI 或订阅等功能。
使用第三方 AI 服务如何收费？
如果你自行连接第三方 AI 服务并填写自己的 API Key，该服务是否收费以对应服务商的官方政策为准。本扩展本身不收取任何费用。
我的数据保存在哪里？
所有设置默认保存在本地浏览器中，不会上传到我们的服务器。你可以随时导入、导出或重置设置。
如何添加自己的 AI 服务商？
进入设置页的「提供商配置」，点击「添加提供商」，选择内置服务商，或使用自定义 API 接入兼容 Chat Completions / Open Responses 的服务。
支持哪些浏览器？
当前提供 Chrome 版本，可在基于 Chromium 的浏览器中加载使用。

Privacy

隐私与数据

鸿鹄 LinguaFlow 以本地运行为主：

  • 设置与配置默认保存在本地，可随时导出、导入或重置。
  • 除非你主动连接第三方 AI 服务，否则不会上传你的文本或数据。
  • 各 AI 服务商的名称与图标归其所有者所有，仅用于标识可接入的服务。
